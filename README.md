# 🐾 Peddy - Dynamic Pet Adoption Platform

## 📖 Project Description
Peddy is a modern, responsive, and feature-rich web application designed to connect animal lovers with pets looking for a forever home. Built using HTML5, Tailwind CSS, DaisyUI, and vanilla JavaScript, it delivers an immersive user experience featuring smooth category filtering, interactive modal details, real-time favorite collections, adoption countdown workflows, and price sorting capabilities.

## ✨ 5 Key Features of the Project
1. **Category-Based Filtering:** Seamlessly switch between different pet categories (Dogs, Cats, Rabbits, Birds) complete with loading spinners and robust "Not Found" fallback messaging when data is unavailable.
2. **Detailed Modal View:** Click on any pet's "Details" button to trigger a responsive modal showcasing complete information including breed, gender, birth date, price, vaccination status, and a detailed biography.
3. **Like & Favorite Sidebar:** Save favorite pets on the fly by clicking the like button, which instantly appends them to a dedicated sidebar preview collection.
4. **Interactive Adoption Workflow:** Experience a rewarding adoption interaction featuring button state disabling, text updates to "Adopted", and an automatic 3-second countdown timer modal dialog.
5. **Price Sorting Feature:** Instantly sort displayed pets in descending order (highest to lowest price) to easily filter options based on budget.

## 🚀 ES6 Features Used
* **Arrow Functions (`() => {}`):** Utilized for clean, concise function expressions and event listener callbacks.
* **Asynchronous JavaScript (`async/await`):** Managed network requests smoothly when fetching pet datasets and individual pet details from JSON endpoints.
* **Destructuring Assignment:** Extracted properties cleanly from objects (e.g., `{pet_name, breed, gender, price, image}` from pet data).
* **Template Literals (`\``):** Dynamically injected variables and HTML structures directly into the DOM using string interpolation.
* **Array Methods (`forEach`, `sort`):** Processed collections and executed sorting logic efficiently.
* **Block-Scoped Variables (`let` & `const`):** Ensured predictable variable scoping and maintained clean code architecture.
